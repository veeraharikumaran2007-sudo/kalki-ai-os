> Next-generation sovereign intelligence platform and developer workspace engineered by Arcues.

## Overview
Kalki AI OS is a high-performance intelligence operating system providing multi-engine reasoning, vision OCR, automated coding agents, and real-time streaming intelligence.

## Features
- **Multi-Engine Intelligence**: Fallback pipelines across OpenRouter, Groq, and Gemini.
- **Enterprise Security**: Apple-grade zero client-side secret exposure with server-side rate limiting.
- **Developer Workspaces**: Code Studio, Vision OCR, Document Synthesizer, and Memory Vault.
- **High Availability**: Serverless edge architecture with sub-second response times.

## Architecture
- **Frontend**: Lightweight vanilla JS, CSS3, DOMPurify sanitization.
- **Backend**: Node.js, Express, Vercel Serverless Functions.
- **Database**: Firebase Firestore & Firebase Auth.
